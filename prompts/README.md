# Recipes for customising your Liftoff site with an AI coding agent

These are copy-paste prompts for tools like Claude Code or Cursor. You do not need to know how to code.

1. Open your copy of the repository in the tool.
2. Open a recipe, fill in the parts in `[square brackets]`, and paste the whole thing.
3. When the agent finishes, ask it to commit and push. Vercel redeploys your site on its own.

| Recipe | What it does |
| --- | --- |
| [change-colours-and-fonts.md](change-colours-and-fonts.md) | New colours and typefaces |
| [add-team-section.md](add-team-section.md) | A "Team" block on your project page |
| [add-custom-page.md](add-custom-page.md) | An extra page, such as `/about` |
| [add-contact-section.md](add-contact-section.md) | A contact block that needs no email service |
| [replace-hero-layout.md](replace-hero-layout.md) | A different top-of-page layout |

Every recipe repeats the rules that keep your visitors safe. Please leave those lines in.
